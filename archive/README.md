# archive

Retired work, kept so the history and ideas are not lost. **Nothing here is maintained, and nothing outside `archive/` may depend on it.** Anything that still runs from here is running by accident.

| Project | Retired | What it was |
|---|---|---|
| [`desktop-dashboard`](desktop-dashboard/README.md) | 2026-10-30 | A live HTML page rendered as the COSMIC desktop background (weather, clock, system stats). Its git history is included. It was previously published as its own repository, `CorbinMeier/desktop`. |

## Rules
- Add a project by moving its folder here with its history, and put an **Archived** banner at the top of its README saying when and why.
- Restoring one means moving it back to the folder that matches its dependencies (`cosmic/`, `apt/` or `libs/`).
