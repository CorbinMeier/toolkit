This is the setup page for the vitals dashboard. It is the only page served without HTTPS.

{{NOTE}}

1. Trust the certificate

The dashboard is served over HTTPS with this laptop's own local certificate authority. Install that certificate once on this device so the browser trusts it, and the page can be installed as an app and keep the screen awake.

Android

  1. Download the certificate above.
  2. Settings, Security, Encryption & credentials, Install a certificate, CA certificate.
  3. Choose the downloaded file (vitals-certificate.crt) and confirm.

iPad and iPhone

  1. Download the certificate above and allow the profile download.
  2. Settings, Profile Downloaded, Install.
  3. Settings, General, About, Certificate Trust Settings: switch on full trust for it.

2. Open the dashboard

Open the address that vitals --serve prints, or use the button below. There is no password: the dashboard is read-only and answers only devices on your own network.
