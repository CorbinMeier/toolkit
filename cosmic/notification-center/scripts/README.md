# scripts

- `check.sh`: ruff check, ruff format --check, unittest (run with `WAYLAND_DISPLAY`/`DISPLAY` unset: tests must never show windows on the user's desktop), then the applet's cargo fmt --check, clippy `--all-targets -D warnings`, test, release build (when `applet/Cargo.toml` exists); last line `CHECK PASS`
- `install.sh [--activate]`: preflight (stock daemon, cosmic-session PATH, typelibs, check.sh), renders `shim/cosmic-notifications` into `~/.local/bin`, creates config/data dirs and default `config.toml` (with `[sound]`, a commented `[shade]` and a commented `[windows]` for `prewarm`, a commented `[images]` for `preview`), `rules.toml` (from `examples/rules.toml`, example sound commented out) and `style.css` (never overwriting any of them), logs rows to `docs/system-changes.md`; `--activate` runs `killall cosmic-notifications` and waits for notifyd to own the name. Replaces the live notification service: run with the user present
- `uninstall.sh [--activate] [--purge]`: removes the shim if it carries our marker; `--activate` swaps the stock daemon back and verifies; `--purge` also deletes config and history
- `shim/cosmic-notifications`: template for the session shim: restart-loops `bin/notifyd` (1 s backoff doubling to 30 s, reset after 60 s uptime), forwards TERM to the daemon on TERM/INT, then dies by that signal (never exit 0: cosmic-session respawns daemon + panel only after a death by signal), never exits otherwise; `~/.config/net.corbinmeier.notifications/disable` makes it exec the stock daemon
- `../bin/notifyd`: launcher (`/usr/bin/python3 -m notifyd` with the repo on PYTHONPATH); flags `--db --config --web-dir --bus-address --no-display --no-sound --no-run -v` (`--no-display` implies `--no-sound`: a `NullPlayer`, no audio; `--no-run` creates no script Runner, so rule and button `run` never execute, while `--no-display` alone keeps it); `--restart` (SIGTERM to the daemon's Python process only, after checking it runs under our shim; the shim restarts it in ~1 s and the command waits for a new pid to own both names; use it instead of `killall cosmic-notifications`, which restarts the panel too and feeds cosmic-session's growing restart backoff), `--show-center`, `--toggle-shade`, `--show-notification ID` and `--press-button ID BUTTON`, `--reply-choice ID CHOICE` and `--reply-text ID TEXT` (prints the JSON result; exit 0 only for `sent`) act as bus clients (ToggleCenter / ToggleShade / ShowNotification / PressButton on the running daemon, then exit, no daemon started): bind `bin/notifyd --toggle-shade` to a keyboard shortcut
- `dev-toast-demo.py`: shows three sample toasts on the live display for ~15 s, then exits (no bus)
- `dev-center-demo.py [--hold] [--snapshot-dir DIR] [--collapse-snapshots DIR]`: opens the center window on the live display over a temp DB of ~46 seeded notifications across 5 days and 8 apps (view state in a temp file), jumps to a details page after 3 s, logs JS -> Python traffic, closes after ~30 s (or stays with `--hold`); `--snapshot-dir` saves WebKit snapshots of the list and details view; `--collapse-snapshots` clicks through expanded / collapsed / mixed / app-only and saves those four (no bus)
- `install-applet.sh`: builds `applet/` in release, installs `~/.local/bin/cosmic-applet-notification-center`, renders the desktop entry into `~/.local/share/applications/`, installs the four icons (full color, plain/`-new`/`-dnd` symbolic; `--icons-only` skips the build and binary, for tests) into `~/.local/share/icons/hicolor/` with the launcher's marker/refuse/skip-unchanged rules and an icon-cache refresh, logs rows to `docs/system-changes.md` (or `NOTIFYD_CHANGES_LOG`); adding it to the panel stays manual. Run with the user present
- `uninstall-applet.sh`: removes that binary, desktop entry and the `-new`/`-dnd` icons, and the full-color + plain icons only when the launcher is not installed (`uninstall-launcher.sh` mirrors this for the applet), logs rows; never touches the panel config
- `dev-shade-demo.py [--hold] [--snapshot-dir DIR] [--check-catcher]`: opens the dashboard shade on the live display over a temp DB of ~25 seeded notifications (5 apps incl. Example App, some expired, DND, with actions) and a temp state file; every callback is a logging fake (dismiss / mark-read act on the temp DB); `--snapshot-dir` saves WebKit snapshots `collapsed.png`, `expanded.png`, `settings.png`; `--check-catcher` emits a button press on the catcher surface and exits 1 unless both surfaces hide (no bus)
- `install-launcher.sh`: installs the "Notification Center" app launcher: renders `resources/net.corbinmeier.NotificationCenter.desktop` (absolute repo path) into `~/.local/share/applications/` and the app + symbolic SVG icons from `resources/icons/` into `~/.local/share/icons/hicolor/{scalable,symbolic}/apps/`, refreshes the desktop/icon caches (warning only), logs rows to `docs/system-changes.md` (or `NOTIFYD_CHANGES_LOG`); refuses to overwrite files without our marker; idempotent. Run with the user present
- `uninstall-launcher.sh`: removes those three files if they carry our marker (others are left with a warning) and logs rows
- `lib/icons.sh`: sourced helpers shared by the install/uninstall scripts (icon paths, refuse-foreign check, cache refresh); not run directly
- `exit-stress.sh [N]`: manual (live display needed, not in check.sh), default N=20: N runs each of `dev-center-demo.py` and `dev-shade-demo.py` with `--snapshot-dir`, then N runs of `bin/notifyd` (display on, `--no-run --no-sound`, temp DB/config/state) on a private `dbus-run-session` bus: 3 notifications, `--toggle-shade`, `--show-center`, 2 s, SIGTERM, expects exit 0; all with `PYTHONFAULTHANDLER=1 MALLOC_PERTURB_=165`; fails on a non-zero exit or stderr matching `corrupted|double-linked|free():|Fatal Python|assertion failed|CRITICAL`; last line `EXIT-STRESS PASS`
